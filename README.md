# BIKS Claude Tools

BIKS Claude Tools - Claude Code plugin marketplace

## Installation

Add this marketplace to Claude Code:

```bash
/plugin marketplace add BikS2013-ClaudeCode/biks-claude-tools
```

## Available Plugins

See the `plugins/` directory for available plugins.

## Plugin Installation

Install individual plugins:

```bash
/plugin install plugin-name@biks-claude-tools
```
