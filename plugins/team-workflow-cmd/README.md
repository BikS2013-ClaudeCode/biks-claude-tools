# team-workflow-cmd

Multi-agent team workflow: orchestrates a coordinated team of subagents to refine, investigate, research, scan, plan, design, implement (parallel coders), review, validate dependencies, build tests, and verify integration for a development request.

> Version 1.0.0. Generated by `packaging/team-workflow-package/build-plugin.sh`.
> Do not hand-edit the bundled files here -- edit the originals under `~/.claude/` and rebuild.

## Commands

- `team-workflow`

Run `/team-workflow <your request>` to launch the multi-agent workflow.

## Bundled agents

The command orchestrates these subagents (all included in `agents/`):

- `request-refiner`
- `codebase-scanner`
- `investigator`
- `technical-researcher`
- `plan-builder`
- `design-builder`
- `tool-doc-config-architect`
- `dependency-validator`
- `test-builder`

## Prerequisites (not bundled)

The workflow and its agents call the following MCP servers, which must be
configured in the host Claude Code environment. They are intentionally **not**
bundled with this plugin:

- `serena`
- `cclsp`
- `context7`

## Installation

This plugin is part of the `biks-claude-tools` marketplace.

```
/plugin marketplace add BikS2013-ClaudeCode/biks-claude-tools
/plugin install team-workflow-cmd@biks-claude-tools
```
